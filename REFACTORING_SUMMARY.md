### 2. Улучшение парсера

**Изменен файл:** `js/workouts.js`

**Новые форматы поддерживаются:**
- `20кг*10` — вес + повторения
- `30сек*0кг` — время + вес
- `25мин:3.8км` — кардио (время + дистанция)
- `30сек`, `1мин`, `2ч` — только время
- `15 раз`, `20 повторений` — только повторения
- `5км`, `1000м` — только дистанция

**Автоматическая детекция типа упражнения:**
- Кардио: беговая дорожка, велотренажёр, эллипс, степпер
- На время: планка, канат, статические упражнения
- Силовые: жим, присед, тяга, подъём, становая, штанга, гантели
- Повторения без веса: отжимания, подтягивания, пресс, брусья

### 3. Система управления упражнениями

**Добавлен UI (аналогично финансам):**
- Список категорий с иконками
- Список базовых упражнений с привязкой к категории
- Список вариантов с группировкой по базовым упражнениям
- Модалки для создания/редактирования/удаления
- Функция объединения вариантов с переносом прогресса

**Файлы:**
- `index.html` — добавлены 3 модалки и подвкладка "Упражнения"
- `js/exercise-modals.js` — вся логика управления
- `css/styles.css` — стили для exercise management

### 4. Обновление графиков

**Изменен файл:** `js/workouts.js`

**Новые метрики по типам:**
- **Силовые:** макс. вес, объём, повторения
- **Кардио:** скорость (км/ч), дистанция (км), время (мин)
- **Повторения без веса:** количество повторений, время
- **На время:** длительность (мин), вес

### 5. Миграция данных

**Добавлена функция:** `migrateOldExercises()` в `js/exercises.js`

**Что делает:**
- Находит все старые упражнения по именам
- Создает для них базовые упражнения и варианты
- Переносит прогресс на новые ID
- Сохраняет оригинальные названия

### 6. Нормализация названий

**Функции в `js/exercises.js`:**
- `normalizeName()` — lowercase, ё→е, trim
- `normalizeExerciseName()` — + удаление спецсимволов

**Автоматическое объединение:**
- "Жим лежа" + "Жим лёжа" + "жим лежа" = один вариант
- "Жим штанги лежа" + "Жим гантелей лежа" = разные варианты (не объединяются)

## 🔧 Технические детали

- **localStorage:** `exercise-data` (структура), `exercise-progress` (прогресс)
- **Firebase:** `lera_diary_v1/{uid}/exerciseCategories`, `baseExercises`, `exerciseVariants`
- **Синхронизация:** вместе с основными данными через `syncToCloud()`
- **Миграция:** запускается при инициализации в `app.js`
